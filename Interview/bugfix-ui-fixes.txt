SECTION 1 — BASIC INTERVIEW QUESTIONS

Q1. Flex item ka default `min-width: auto` overflow kyun kara sakta hai?

Answer:
Item apne min-content size se chhota shrink nahi hota; long unbreakable content parent se bahar push kar sakta hai.

Q2. `min-width: 0` kya fix karta hai?

Answer:
Flex/grid item ko intrinsic min-content width ke neeche shrink allow karta hai, so container constraint apply ho sakta hai.

Follow-up Q2.1: Kya `width: 100%` same fix hota?

Answer:
Guaranteed nahi. Intrinsic minimum width flex sizing ko still block kar sakti hai; `min-width:0` specifically shrink constraint release karta hai.

Q3. `overflow-wrap: anywhere` aur `word-break` me kya difference hai?

Answer:
`overflow-wrap:anywhere` overflow avoid karne ke liye arbitrary break opportunity deta hai; `word-break` language/text breaking behavior ko more aggressively change kar sakta hai.

Q4. `max-width: 100%` ka role kya hai?

Answer:
Bubble ko containing block se wider hone se cap karta hai; alone intrinsic shrink issue solve nahi karta, isliye `min-width:0` bhi important hai.
